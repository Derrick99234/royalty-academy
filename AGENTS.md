# Royalty Academy (single-page marketing site)

Next.js 16.3.0 (App Router), React 19, Tailwind CSS v4, TypeScript. No tests, no CI, no monorepo, no `.env`.

## Commands

- `npm run dev` — dev server (`next dev`)
- `npm run build` / `npm run start` — production build / serve
- `npm run lint` — `eslint` (flat config, `eslint.config.mjs`; only `next` core-web-vitals + typescript rules)
- `npx tsc --noEmit` — typecheck. There is **no `typecheck` script**; run this directly. Verify with it after changes.

## Architecture

- Two routes: the home page `src/app/page.tsx` and the full gallery `src/app/gallery/page.tsx`. No API routes, no data fetching.
- Gallery data (groups of `impact-1000-training-*` images split by event month/year) is shared from `src/app/gallery-data.ts`, imported by both pages. The home page gallery section shows one preview card per date group linking to `/gallery#<group-id>`; the gallery page renders every group as an anchored section.
- Other sections are hardcoded JSX; data (nav links, training topics) lives in `const` arrays at the top of `page.tsx`. The only component is the inline `TrainingCard`.
- To add a section/page, follow the existing pattern: data array + Tailwind classes. All copy is real org content (Royalty Academy / NYSC "IMPACT 1000" training); keep it consistent.

## Tailwind v4 (no `tailwind.config.js`)

- All design tokens live in the `@theme inline` block in `src/app/globals.css`, **not** a config file. Brand colors are custom token names (`primary`, `secondary`, `tertiary`, `surface`, `on-surface-variant`, `surface-container-low`, ...). Use these tokens, not the default palette.
- v4 renamed gradient utilities: use `bg-linear-to-*` (not `bg-gradient-to-*`). PostCSS runs `@tailwindcss/postcss` only.
- Custom classes `.hero-gradient`, `.gold-accent-line`, `.material-symbols-outlined` are defined in `globals.css`.

## Fonts & icons

- `next/font/google` in `src/app/layout.tsx` (Montserrat, Inter, Public_Sans) exposes CSS vars mapped to utilities `font-headline` / `font-body` / `font-label`.
- Material Symbols loaded via a Google Fonts `<link>` in `layout.tsx`; use class `material-symbols-outlined` with a ligature name (e.g. `school`, `arrow_forward`).

## Images

- Images are imported from `public/` by relative path in `page.tsx` (e.g. `import logo from "../../public/royalty-academy-logo.jpeg"`) and passed to `next/image` `src`. Add new photos to `public/images/` and import them the same way.
- The gallery photos live in `public/images/` as `impact-1000-training-<n>.jpg` and are referenced by URL string (`/images/...`) from `gallery-data.ts` — do not rename or renumber them without updating `gallery-data.ts`.

## Next 16 quirks verified here

- `LayoutProps<"/">` (used in `layout.tsx`) and `PageProps` are global generic route types — no import needed.
- `next-env.d.ts` references generated types in `.next/dev/types/` (regenerated by `next dev`).

## Tools

- `CLAUDE.md` just includes `AGENTS.md`; no separate guidance.
